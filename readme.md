 TaskFlow Pro

A project management application that allows teams to:
- Create projects
- Add and assign tasks
- Track progress and deadlines
- Manage users securely with authentication

Tech Stack
- Node.js
- Express
- SQLite (scalable design)
- Sequelize ORM
- JWT Authentication

Features (Milestone 1)
- User registration & login
- Password hashing and reset
- JWT access & refresh tokens
- Secure token rotation
- Admin user management
- Soft deletes

Project Status
🚧 In active development
